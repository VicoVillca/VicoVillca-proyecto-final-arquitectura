# Sistema de Gestión de APIs - Documentación de Arquitectura

## 📋 Descripción del Proyecto
Este repositorio contiene la documentación técnica y el diseño arquitectónico de un sistema de gestión de APIs. Como parte de una práctica de arquitectura de software, se documentan los contratos de API y los diagramas de sistema utilizando buenas prácticas de Git y GitHub.

## 🎯 Objetivo
Demostrar el flujo de trabajo profesional de un arquitecto de software mediante:
- Gestión de issues y ramas por funcionalidad
- Documentación técnica de APIs (REST y GraphQL)
- Diseño de arquitectura de sistemas
- Uso de Pull Requests para integración de cambios

## 🚀 Tecnologías Documentadas
- **REST API**: Endpoints, métodos HTTP, códigos de respuesta
- **GraphQL**: Esquemas, tipos, queries y mutations
- **Arquitectura**: Diagramas de componentes y flujo de datos

## 🤝 Contribución
Este es un proyecto educativo que sigue el flujo de trabajo:
1. Crear issue para nueva funcionalidad
2. Desarrollar en rama feature/*
3. Abrir Pull Request a main
4. Merge tras revisión
